CSV schema & usage (click to expand)

Required header row. Columns (case-insensitive):

  • type: One-Liner | Statement | Assertion/Reason
  • question: For One-Liner & Statement (main stem)
  • statements: For Statement type only. Semicolon-separated list
  • assertion, reason: For Assertion/Reason type
  • option_a ... option_d: For One-Liner & Statement; leave blank for Assertion/Reason
  • answer: One of A, B, C, D
  • explanation_correct, explanation_incorrect: Optional
  • subject: Optional tag (e.g., Physics/Chemistry/Biology)
